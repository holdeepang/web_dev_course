How it works:
1. every website www.abc.com --> points to an ip address 00.00.00.00
2. User sends request to server, when click on ip address
3. request arrive to router (internet IPv4)
4. router then redirect to the machine / server actually hosting the website (device IPv4)
5. Port forwarding: through specific / default ports (eg: http = 80, https = 443)
6. All the php, html, css, js then send through to user again (which you will know their ip address in Apache access.log)

Website hosting needed:
Apache = basically the HTTP server
PHP = server side content management system language
MySQL / MariaDB = Data management and query
phpMyAdmin = A more useful combination of php and MySQL
